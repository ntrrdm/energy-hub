# Данные кейса case6

`raw/` содержит шесть исходных CSV. Скрипт `scripts/build-case6-data.js` выбирает последние 96 записей по каждому файлу, агрегирует Demand в 24 часовых интервала и отдельно агрегирует среднюю мощность Grid и PV. Пустые измерения остаются `null`; нулевое потребление из пропуска не выводится.

Результат сохраняется в `case6-aggregated.json` и импортируется основным React-интерфейсом. Для пересборки выполните `npm run data` из корня проекта.
